# Styledown

A free, open-source, fully client-side Markdown editor for turning Markdown into beautifully styled, print-ready documents (PDF, HTML, Markdown).

This repo is under active development. See [`docs/DESIGN.md`](docs/DESIGN.md) for the design decisions and build order.

## Development

```bash
pnpm install
pnpm dev
```
